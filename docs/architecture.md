## 请求处理流程

```
用户请求
   │
   ▼
Ghost 核心路由 (Express)
   │
   ├── 前台页面请求 → 主题模板渲染 (Handlebars) → 返回 HTML
   │
   ├── Content API 请求 (/ghost/api/content/*) → JSON 数据
   │
   └── Admin 请求 (/ghost/*) → Ember 管理后台
         │
         ▼
   数据访问层 (Knex + Bookshelf)
         │
         ▼
   SQLite 数据库 (ghost-dev.db)
```

## 自定义搜索功能架构

### 本地全文索引搜索

```
用户点击搜索按钮
   │
   ▼
搜索弹窗打开 (search-modal.hbs)
   │
   ▼
首次加载：调用 Ghost Content API 获取所有文章
   │  GET /ghost/api/content/posts/?key=xxx&include=tags&limit=all&formats=plaintext
   ▼
构建本地索引（内存中）
   │  - 每篇文章：标题 + 纯文本内容 + 标签名
   │  - 分词：英文单词 + 中文 2-gram
   ▼
用户输入关键词
   │
   ▼
搜索匹配 (search.js)
   │  - 完整短语匹配（权重最高）
   │  - 标题匹配（权重 10）
   │  - 标签匹配（权重 5）
   │  - 内容匹配（权重 1）
   │  - 匹配阈值：短查询≥1 token，长查询≥2 tokens 或完整短语
   ▼
结果排序 + 关键词高亮 (<mark> 标签)
   │
   ▼
无结果时显示建议（热门标签 + 推荐文章）
```

## 技术栈

| 层级 | 技术 |
|------|------|
| 运行时 | Node.js v22 LTS |
| 博客核心 | Ghost v6.59.0 (Express + Bookshelf + Knex) |
| 数据库 | SQLite3 |
| 管理后台 | Ember.js |
| 主题模板 | Handlebars |
| 主题构建 | Gulp + PostCSS |
| 前端搜索 | 原生 JavaScript (无第三方依赖) |
| 版本管理 | Git |
| 包管理 | pnpm / npm |
